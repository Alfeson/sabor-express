# Sabor Express

Um aplicativo de linha de comando (CLI) simples e interativo para gerenciamento de restaurantes, desenvolvido totalmente em Python.

## Objetivo do Projeto
Este projeto foi desenvolvido como uma iniciativa prática para estruturar o portfólio no GitHub e aplicar conceitos fundamentais de Python, tais como:
- Criação e organização de funções.
- Manipulação de listas.
- Estruturas de repetição e controle de fluxo (`for`, `if/elif/else`, tratamento de erros com `try/except`).
- Interação fluida com o usuário via terminal.

## Funcionalidades
- **Cadastrar restaurante:** Permite adicionar novos estabelecimentos ao sistema.
- **Listar restaurantes:** Exibe de forma limpa todos os restaurantes já cadastrados.
- **Ativar/Desativar restaurante:** Opção no menu pronta para receber a lógica de alteração de status do estabelecimento.
- **Navegação Contínua:** Limpeza de tela automática para manter o terminal organizado durante o uso.

## Como executar o projeto

### Pré-requisitos
- Python 3.x instalado na sua máquina.

### Passos para rodar
1. Baixe ou faça o clone deste repositório.
2. Abra o terminal (ou prompt de comando) na pasta onde o arquivo do código está salvo.
3. Execute o comando abaixo (substitua `app.py` pelo nome exato do seu arquivo, se for diferente):
   ```bash
   python app.py
   ```

> **Nota sobre o Sistema Operacional:** O código atual utiliza o comando `os.system('cls')` para limpar a tela, que é nativo do **Windows**. Se você estiver utilizando **Linux** ou **macOS**, pode ser necessário alterar essa linha no código para `os.system('clear')`.

## Tecnologias Utilizadas
- **Python 3**
- Biblioteca nativa `os`
